To initialize git in a folder
>> git init

To check status of git
>> git status

To add a file to tracking (To stage the file for commit)
>> git add <filename>

To remove file from tracking (Unstage the file)
>> git rm --cached <file>

To check the history
>> git log
To get a shorter version
>> git log --oneline

To show what changes occured (Shows what files are modified)
>> git show

To show exactly what has changed (Shows what are the modifications done in each file. like a comparison)
>> git diff

To restore a file
>> git restore <filename>

Once Staged, but to see the difference
>> git diff --Staged

To temporarily switch back to an old commit
>>git switch --detach <commitID>

To switch back to master/main (latest)
>> git switch <main/master>

You don't want commit 3 due to some issue. Now you want to have commit 2 as latest (like a rollback). 
This deletes the git history too
>> git reset --hard <commitID>

If you want to rollback but preserve the history. Git creates a new commit that reverses to D
>>git revert <commitID>

If we revert and we mess up
>> git reflog

Git rename a branch to main
>>git branch -M main

Branches in git

Create a new branch and switch to it immediately
>>git switch -c staging

List all the Branches
>> git branch

To switch to main / staging if branch already present
>> git switch <main/staging>


Merge staging to main
Suppose if the changes made in staging is production ready, and we feel this can be pushed to main
1. Switch and be in main
>> git switch main
2. check if nothing is pending to commit
>> git status
3. Merge staging to main
>> git merge staging


Github and remote git repository management

To check git remote repository connected. returns nothing if not connected
>> git remote

To connect to a remote repository
>> git remote add origin
This connects to a remote github repository created. git remote -v can be used to check cnnection

Once repository is connected, to push our branch to github
1. Check which branch is active Now
>> git branch
2. Check pending changes or anything left to commit
>> git status
3. Push main to remote
>> git push -u origin main

Once we have pushes made for each local branches to origin, "git branch -a" shows local branches as well as remote origin
After remote origins are present, all we have to do is git push while in the branch to push changes to remote instead of git push origin staging
>>git push
